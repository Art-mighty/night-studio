# Lumia brand files (for Lumia Merch Lab)

Copied on 2026-10-16 from the Lumia brand repo (`Lumia_marketing/brand/logos/`, the final export of 2026-09-12),
with the owner's permission, so the course can offer them for download on its Brand Kit screen (`#/brand-kit`).

- `logos/*-ink.png` / `*-amber.png`: trimmed transparent PNGs, about 1,550 px wide. Ink (#0a0a08) goes on light
  backgrounds, amber (#f6df9f) on dark ones.
- `logos/Lumia-mark-ink-transparent.svg` and `Lumia-mark-tile-amber.svg`: the official vector star.
- `logos/Lumia-mark-amber-transparent.svg`: the same star path, filled with the official amber (added for the course,
  for dark garments).

Don't edit, recolour or redraw these files. Fonts aren't copied: Marcellus (the wordmark) and Space Grotesk are free
Google Fonts that Figma already has.
